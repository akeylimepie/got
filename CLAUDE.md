# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Одностраничная утилита: тянет карты «Tides of Battle» из настольной «Игры престолов» (2-я редакция) для атакующего
и защитника. Весь проект — один `index.html` с инлайновыми CSS, SVG и JS; ни сборки, ни зависимостей, ни тестов,
ни линтера. Шрифты грузятся с Google Fonts.

Запуск — открыть `index.html` в браузере (или `open index.html`).

## Устройство

- Колода — массив строк `deck` (24 карты, состав по правилам); эмодзи в строке и есть значок карты (💀, 🏰, 🗡️),
  `icons` переводит его в id SVG-символа. Состав колоды меняется только там.
- Случайность — `crypto.getRandomValues` через `getRandomInt(max)` (включительно до `max`), перемешивание —
  Фишер–Йетс в `shuffle`.
- Один бой — одна загрузка страницы: по FAQ 2.0 колода замешивается заново перед каждым боем, поэтому `deck` не
  мутируется, а бой тянет из копии `pile`. Новый бой — перезагрузка.
- Карты сдаются рубашкой вверх; тап по любой вскрывает обе. Валирийский клинок — один раз за бой: меняет свою карту
  на следующую из `pile`, сброшенная в колоду не возвращается.
- Лицевая сторона рисуется в `renderFace` как SVG 200×300 (пропорции карты 41×63 мм). Раскладка как у настоящих
  карт: без значка сила по центру, со значком — сила сверху, под ней линия и значок.
- Тема одна, тёмная.
